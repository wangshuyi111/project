## 项目简介

本项目通过抓取就业信息网招聘数据，提取岗位、薪资、地区等关键信息，使用 Python 进行数据分析，并通过 ECharts 在前端实现多维数据可视化。

**数据规模：**
- 招聘岗位总数：31,035 条
- 覆盖城市：247 个
- 含薪资岗位：28,979 条

**核心功能：**
- **数据采集**：从就业信息网抓取招聘数据，存储为 CSV 文件
- **数据清洗**：解析薪资字符串（如 `"5-8千/月"` → 最低/最高/平均薪资），清洗城市、公司规模、行业等字段
- **统计分析**：10 项统计分析维度，结果导出为 JSON
- **可视化展示**：ECharts 大屏展示，含 4 张概览卡片 + 10 个图表 + 分析结论
